# 0007. PDF com PDFBox em modo estrito

**Situação:** aceita

## Decisão

Apache PDFBox 3.0.8 (Apache-2.0, Java puro), com `jbig2-imageio` para páginas digitalizadas.

- **Estrito:** o PDFBox registra um erro e deixa um vazio quando não decodifica uma imagem. Página em branco não é
  sucesso; o Morph interrompe e explica.
- Imagens embutidas no PDF também obedecem ao limite de pixels, antes de decodificar.
- JPEG é incorporado sem recompressão, **sem metadados**: EXIF, localização, miniaturas, comentários e bytes após o
  fim da imagem (onde celulares guardam vídeos) são removidos. Com perfil de cor, CMYK ou rotação, é recomprimido.
- PDFs gerados são reproduzíveis: sem data, autor, produtor ou identificador aleatório.
- Cache em disco e índice de fontes são desviados dos padrões do PDFBox (temporário do sistema e pasta pessoal) para a
  área do Morph. Logs do PDFBox são desligados, pois podem citar o documento.

## Fora de escopo, por enquanto

JPEG 2000 dentro de PDF: o decodificador Java disponível (`jai-imageio-jpeg2000`) usa a licença própria do JJ2000, não aprovada pela OSI.
PDFs protegidos por senha são recusados com mensagem própria.
